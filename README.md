# 🎨 Gradio — CSS Gradient Studio

A tactile, responsive gradient studio for designing layered CSS backgrounds and exporting them for production projects.

## Features

- Live linear and radial gradients with constrained color stops
- Grid and dot overlays
- Linear and radial masks with fade, spotlight, vignette, and edge presets
- Undo, redo, reset, and randomize
- Visible CSS, Tailwind, React, CSS-variable, and SVG output
- SVG and 1600×900 PNG downloads
- Keyboard-accessible focal-point controls and reduced-motion support

## Usage

```bash
npm install
npm run dev
```

Quality checks:

```bash
npm run lint
npm run typecheck
npm test
npm run build
```
